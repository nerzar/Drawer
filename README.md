# Ящик

Выезжающая панель для окон Windows. Хоткей выдвигает окно приложения
сбоку экрана поверх остальных, повторный хоткей убирает его за край.
Окно не закрывается и не сворачивается — состояние сохраняется.

Написано после того, как WTQ на этой машине оказался нерабочим:
он падал на свёрнутых окнах, зависал на служебных окнах PhpStorm,
а зависший экземпляр блокировал все последующие запуски.

## Запуск

Нужен AutoHotkey v2. Запускается двойным щелчком по `drawer.ahk`
или ярлыком на рабочем столе.

| Хоткей | Действие |
|---|---|
| `Ctrl+Alt+1` | VS Code |
| `Ctrl+Alt+2` | PhpStorm |
| `Ctrl+Alt+0` | выход, окна возвращаются на исходные места |

Второй запуск не конфликтует с первым: новый экземпляр вытесняет старый.

## Настройка

Всё в начале `drawer.ahk`, в блоке `НАСТРОЙКИ`. Массив `apps` задаёт
приложения: имя процесса, класс окна, край и ширину панели в процентах.
`animMs` и `animSteps` управляют анимацией, `animSteps := 0` выключает её.

После правки перезапустить скрипт.

## Как выбирается край

Если с указанной стороны стоит второй монитор, программа выберет
противоположный край сама — иначе спрятанное окно оказалось бы видно
на соседнем экране. Панель появляется на том мониторе, где курсор.

Спрятанное окно паркуется за границей всего виртуального рабочего
стола. Намеренно не используется `WinHide`: скрытое им окно после
аварийного завершения программы вернуть штатными средствами Windows
нельзя, а припаркованное — находится и возвращается при следующем запуске.

## Чек-лист приёмки

Составлен по отказам, которые дал WTQ. Все пункты проверены.

| Сценарий | Результат |
|---|---|
| Второй экземпляр не блокирует запуск | пройден |
| Свёрнутое окно разворачивается, программа не падает | пройден |
| Окна без заголовка не захватываются | пройден |
| Приложение не запущено — уведомление, без падения | пройден |
| Выход возвращает окна на исходные места | пройден |
| Настройки не теряются | пройден, это константы в файле |
| Работа после перезагрузки | проверяется вручную |

## Известные ограничения

- При нескольких окнах одного приложения берётся окно наибольшей площади.
- Автозапуска нет: программа запускается вручную.
- Окно остаётся в Alt+Tab и на панели задач.

## Что дальше

Отложено до того, как база покажет себя в работе:
убрать окно из Alt+Tab, прятать при потере фокуса,
захват любого активного окна по хоткею.
