# Бриф

## Задача

Программа, которая по горячей клавише выдвигает окно нужного приложения
сбоку экрана поверх остальных окон, а повторным нажатием убирает его за
край. Окно при этом живёт постоянно: не закрывается, не сворачивается,
состояние работы сохраняется.

## Откуда взялась потребность

При десятке открытых окон переключение через Alt+Tab перестаёт быть
быстрым: нужное окно приходится искать глазами в ленте эскизов. Идея —
вынести пару рабочих окон из общего потока в отдельный «карман», доступ
к которому идёт по прямому хоткею, а не перебором.

Ближайший аналог по ощущению — выпадающая консоль в Quake и выезжающие
панели в macOS.

## Пользователь

Один человек, разработчик. Основные окна: PhpStorm, VS Code, браузер,
терминал. Две машины ролей не играет — только эта: Windows 11,
два монитора 1920×1080, второй расположен слева от основного.

## Что нужно

- Выезд и уезд окна по горячей клавише, с анимацией
- Несколько приложений, у каждого свой хоткей
- Настраиваемые сторона выезда и ширина панели
- Окно не теряет состояние между показами

## Что не нужно

- Управление раскладкой окон, тайлинг, рабочие столы
- Графический интерфейс настроек
- Поддержка чужих машин и установщик
- Кроссплатформенность

## Критерии успеха

Программа считается удавшейся, если после перезагрузки её достаточно
запустить один раз, и дальше она отрабатывает хоткеи весь день без
перезапусков, зависаний и потери настроек.

Отдельное требование, выстраданное на предшественнике: **программа не
должна оставлять окна в состоянии, из которого пользователь не может
их вернуть штатными средствами Windows.**
