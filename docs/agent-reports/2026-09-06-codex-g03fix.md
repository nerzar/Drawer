## 4. Important decisions

- Existing membership in `watched` is the runtime evidence that Drawer legitimately activated or focused the window. Reconcile preserves that evidence while `hideOnBlur` remains enabled and the window remains live, bound, and deployed.
- A new watcher is created during reconcile only when the authoritative configuration has `activateOnShow=true`; an unrelated Apply therefore cannot enroll a normally shown `activateOnShow=false` window.
- `SlotOf(hwnd)` is the single behavior authority for duplicate bindings and retains its documented permanent-first precedence.
- Timer re-arm and cleanup remain based on the final `watched` membership, preserving live `blurMs` changes and multi-watcher behavior.
