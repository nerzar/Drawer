## ╨з╤В╨╛ ╤Б╤З╨╕╤В╨░╤В╤М Chat/session ID

╨Э╨╡ ╨┐╤А╨╕╨┤╤Г╨╝╤Л╨▓╨░╤В╤М ╨╕╨┤╨╡╨╜╤В╨╕╤Д╨╕╨║╨░╤В╨╛╤А.

╨Х╤Б╨╗╨╕ ╨║╨╗╨╕╨╡╨╜╤В ╤А╨╡╨░╨╗╤М╨╜╨╛ ╨┐╨╛╨║╨░╨╖╤Л╨▓╨░╨╡╤В stable conversation/session/thread/task ID тАФ ╨╖╨░╨┐╨╕╤Б╨░╤В╤М ╨╡╨│╨╛ ╨┤╨╛╤Б╨╗╨╛╨▓╨╜╨╛. ╨Х╤Б╨╗╨╕ ╨╜╨╡ ╨┐╨╛╨║╨░╨╖╤Л╨▓╨░╨╡╤В, ╨┐╨╕╤Б╨░╤В╤М `NOT_EXPOSED`.

╨Т ╤В╨░╨║╨╛╨╝ ╤Б╨╗╤Г╤З╨░╨╡ ╨╛╨▒╤П╨╖╨░╤В╨╡╨╗╤М╨╜╤Л `Chat title` (╨╡╤Б╨╗╨╕ ╨▓╨╕╨┤╨╡╨╜) ╨╕ `Search anchor`. `Search anchor` тАФ ╤Г╨╜╨╕╨║╨░╨╗╤М╨╜╨░╤П ╤Д╤А╨░╨╖╨░ ╨┤╨╗╤П ╨┐╨╛╨╕╤Б╨║╨░ ╨╕╤Б╤В╨╛╤А╨╕╨╕, ╨╜╨░╨┐╤А╨╕╨╝╨╡╤А:

`Drawer TASK C02 тАФ General+dynamic override тАФ codex/20260906`

╨Р╨│╨╡╨╜╤В ╨┤╨╛╨╗╨╢╨╡╨╜ ╨▓╤Б╤В╨░╨▓╨╕╤В╤М ╤Н╤В╨╛╤В anchor ╤В╨░╨║╨╢╨╡ ╨▓ ╤Б╨▓╨╛╨╣ ╤Д╨╕╨╜╨░╨╗╤М╨╜╤Л╨╣ ╨╛╤В╨▓╨╡╤В ╨┐╨╛╨╗╤М╨╖╨╛╨▓╨░╤В╨╡╨╗╤О/╨╛╨┐╨╡╤А╨░╤В╨╛╤А╤Г, ╤З╤В╨╛╨▒╤Л ╨╡╨│╨╛ ╨╝╨╛╨╢╨╜╨╛ ╨▒╤Л╨╗╨╛ ╨╜╨░╨╣╤В╨╕ ╤З╨╡╤А╨╡╨╖ ╨┐╨╛╨╕╤Б╨║ ╨┐╨╛ ╤З╨░╤В╨░╨╝.

## ╨Я╤А╨░╨▓╨╕╨╗╨░

- ╨Ю╤В╤З╤С╤В ╤Б╨╛╨╖╨┤╨░╤С╤В╤Б╤П **╨┤╨╛** ╤Д╨╕╨╜╨░╨╗╤М╨╜╨╛╨│╨╛ push ╨╖╨░╨┤╨░╤З╨╕ ╨╕ ╨▓╤Е╨╛╨┤╨╕╤В ╨▓ ╨╡╤С final commit ╨╗╨╕╨▒╨╛ ╨▓ ╨╛╤В╨┤╨╡╨╗╤М╨╜╤Л╨╣ ╨╖╨░╨▓╨╡╤А╤И╨░╤О╤Й╨╕╨╣ commit ╤В╨╛╨╣ ╨╢╨╡ feature-╨▓╨╡╤В╨║╨╕.
- `Final SHA` ╨▓ ╤Б╨░╨╝╨╛╨╝ ╨╛╤В╤З╤С╤В╨╡ ╨╝╨╛╨╢╨╜╨╛ ╨╛╤Б╤В╨░╨▓╨╕╤В╤М ╨║╨░╨║ `PENDING_FINAL_COMMIT`, ╨╡╤Б╨╗╨╕ SHA ╨╡╤Й╤С ╨╜╨╡ ╤Б╤Г╤Й╨╡╤Б╤В╨▓╤Г╨╡╤В; ╨┐╨╛╤Б╨╗╨╡ commit ╨░╨│╨╡╨╜╤В ╨╛╨▒╤П╨╖╨░╨╜ ╤Б╨╛╨╛╨▒╤Й╨╕╤В╤М ╤Д╨░╨║╤В╨╕╤З╨╡╤Б╨║╨╕╨╣ final SHA ╨▓ ╤Б╨▓╨╛╤С╨╝ ╤Д╨╕╨╜╨░╨╗╤М╨╜╨╛╨╝ ╨╛╤В╨▓╨╡╤В╨╡. ╨Х╤Б╨╗╨╕ ╤Г╨┤╨╛╨▒╨╜╨╛, ╤Б╨┤╨╡╨╗╨░╤В╤М ╨▓╤В╨╛╤А╨╛╨╣ ╨╝╨░╨╗╨╡╨╜╤М╨║╨╕╨╣ report-only commit ╤Б ╨╖╨░╨┐╨╛╨╗╨╜╨╡╨╜╨╜╤Л╨╝ SHA.
- ╨Ф╨╗╤П ╨┐╨░╤А╨░╨╗╨╗╨╡╨╗╤М╨╜╤Л╤Е ╨░╨│╨╡╨╜╤В╨╛╨▓ ╨╛╨▒╤П╨╖╨░╤В╨╡╨╗╤М╨╜╨╛ ╤Г╨║╨░╨╖╤Л╨▓╨░╤В╤М ╤В╨╛╤З╨╜╤Л╨╣ `Worktree`.
- ╨Х╤Б╨╗╨╕ ╤А╨░╨▒╨╛╤В╨░ ╨┐╤А╨╛╨┤╨╛╨╗╨╢╨░╨╡╤В ╤Б╤В╨░╤А╤Л╨╣ ╤З╨░╤В/╤Б╨╡╨░╨╜╤Б, Run ID ╨╛╤Б╤В╨░╤С╤В╤Б╤П ╨┐╤А╨╡╨╢╨╜╨╕╨╝; ╨╡╤Б╨╗╨╕ ╤Н╤В╨╛ ╨╜╨╛╨▓╤Л╨╣ ╤З╨░╤В ╨┤╨╗╤П ╤В╨╛╨╣ ╨╢╨╡ ╨╖╨░╨┤╨░╤З╨╕ тАФ ╨╜╨╛╨▓╤Л╨╣ Run ID ╨╕ ╤Б╤Б╤Л╨╗╨║╨░ ╤В╨╡╨║╤Б╤В╨╛╨╝ ╨╜╨░ ╨┐╤А╨╡╨┤╤Л╨┤╤Г╤Й╨╕╨╣ Run ID ╨▓ ╤А╨░╨╖╨┤╨╡╨╗╨╡ Result/Important decisions.
