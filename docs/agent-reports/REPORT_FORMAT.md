# Формат отчёта агента

Отчёт нужен только для текущей или недавно завершённой задачи. Старые отчёты не являются актуальным состоянием проекта и не должны читаться подряд как контекст.

Минимально указывать:

- Task / Run ID;
- агент и модель;
- ветку и worktree;
- Base SHA;
- Code SHA итогового кода;
- короткий результат;
- что реально проверено;
- что осталось нерешённым;
- следующий шаг, если он очевиден.

Правила:

- архитектурные ссылки на реализацию указывают на `Code SHA`, а не на report-only commit;
- не выдумывать session/chat ID, если клиент его не показывает;
- не писать chain-of-thought;
- не создавать дополнительный commit только ради вписывания SHA самого отчёта;
- актуальное состояние проекта берётся из Git и `AGENT_BOARD.md`, а не из старых reports.
