## Goal

Воспроизвести и устранить причину ошибки сборки `Ahk2Exe` exit code 17, восстановить работоспособность `build/build.ps1` и проверить гарантии безопасности конфигурации (config preservation) и сборки релиза.

## Result

1. **Фактическая причина exit code 17 воспроизведена и доказана**:
   - `0x11` (17 в десятичной системе) — код синтаксической ошибки в Ahk2Exe (`Error: The script contains syntax errors`).
   - Фактический текст ошибки компилятора:
     `src\webview\SettingsWebView.ahk (25) : ==> This function declaration conflicts with an existing Func. Specifically: ApplyDwmTitlebarTheme`
   - Ошибка была вызвана тем, что `ApplyDwmTitlebarTheme` была объявлена одновременно в `src/drawer.ahk` и в `#Include`'нутом `src/webview/SettingsWebView.ahk`.
   - При отсутствии ключа `/silent` Ahk2Exe выводил GUI-диалог `MsgBox` и ожидал интерактивного нажатия кнопки, после закрытия которого возвращал код 17.
2. **DWM-дублирование устранено**:
   - Полная реализация темы DWM (dark mode + DWMWA_CAPTION_COLOR 0x001C1817 + DWMWA_TEXT_COLOR 0x00EFEDED + DWMWA_BORDER_COLOR 0x00352E2A + DllCall fallback без custom chrome) перенесена в `src/drawer.ahk`.
   - Из `src/webview/SettingsWebView.ahk` удалено дублирующее определение функции; вызовы `ApplyDwmTitlebarTheme(this.Window.Hwnd)` обращаются к единой реализации.
3. **Улучшения build/build.ps1**:
   - В аргументы запуска Ahk2Exe добавлен ключ `/silent`, благодаря чему компилятор не блокирует консольные и автоматические сценарии модальными окнами, а выводит ошибки в stdout/stderr и возвращает код ошибки.
   - В функции `Test-Embedded` вызов `[Text.Encoding]::Latin1` заменён на `[Text.Encoding]::GetEncoding("ISO-8859-1")`, что устранило падение по `InvokeMethodOnNull` в Windows PowerShell 5.1 (`powershell.exe`).
   - Файл сохранён с UTF-8 BOM, устранив синтаксический сбой парсера Windows PowerShell 5.1 на кириллических строках.
4. **Проверки сохранности конфигурации и упаковки (config safety)**:
   - Fresh build: создаёт дефолтный `dist/Drawer-v0.1.2-beta/config.ini`, идентичный `src/config.ini`.
   - Rebuild: при изменении `dist/Drawer-v0.1.2-beta/config.ini` повторная сборка сохраняет изменения и не перезаписывает файл.
   - Release zip: проверено, что `.log` файлы (включая тестовый `drawer-debug.log`) исключаются из результирующего архива `dist/Drawer-v0.1.2-beta.zip` (0 файлов `.log` в архиве).
