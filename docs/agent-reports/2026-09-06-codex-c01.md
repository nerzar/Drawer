# C01 — Slots product contract

Branch: `codex/slots-user-contract`.

Implemented the review fixes on top of the existing persisted show/hide hotkey
model. WebView uses a read-only keyboard-capture field and sends a human
combination. Native Settings uses AutoHotkey's `Hotkey` control. Dynamic Slots
now expose release through the existing `slot.release` backend and a draft
action that resets behavior overrides to General without changing the slot
hotkey. The legacy extra-focus-hotkey is not read, registered, or exposed by
the Settings DTO.
