# Требования

## Функциональные

| № | Требование | Приоритет |
|---|---|---|
| F1 | Хоткей выдвигает окно приложения сбоку и убирает обратно | v1 |
| F2 | Анимация выезда и уезда, длительность настраивается | v1 |
| F3 | Несколько приложений, у каждого свой хоткей | v1 |
| F4 | Сторона и ширина панели настраиваются для каждого приложения | v1 |
| F5 | Окно не закрывается и не сворачивается, состояние сохраняется | v1 |
| F6 | Панель появляется на мониторе, где находится курсор | v1 |
| F7 | Явный выход, возвращающий окна на исходные места | v1 |
| F8 | Спрятанное окно не попадает в Alt+Tab и на панель задач | потом |
| F9 | Окно уезжает само, когда фокус ушёл в другое приложение | потом |
| F10 | Захват любого активного окна по хоткею, без правки настроек | потом |
| F11 | Автозапуск вместе с системой | потом |
| F12 | Выбор конкретного окна, когда у приложения их несколько | потом |

## Нефункциональные

| № | Требование |
|---|---|
| N1 | Запуск второго экземпляра не блокирует работу: новый вытесняет старый |
| N2 | Некорректное окно не приводит к падению — программа продолжает работать |
| N3 | Настройки хранятся в исходном файле и не переписываются программой |
| N4 | Любое состояние окна обратимо штатными средствами Windows |
| N5 | Нет фоновых служб, сетевых портов и внешних процессов |
| N6 | Изменение поведения — правка одной строки без пересборки |

## Ограничения

- Windows 11, два монитора, второй слева от основного
- Требуется установленный AutoHotkey v2
- Целевые приложения: VS Code (`Code.exe`), PhpStorm (`phpstorm64.exe`)
