# Требования

## Функциональные

| № | Требование | Приоритет |
|---|---|---|
| F1 | Хоткей выдвигает окно приложения сбоку и убирает обратно | v1 |
| F2 | Анимация выезда и уезда, длительность настраивается | v1 |
| F3 | Девять слотов `Ctrl+Alt+1…9`, у каждого своё окно | v1 |
| F4 | Для каждого приложения настраиваются слот, монитор, сторона, размер панели и поведение при показе | v1 |
| F5 | Окно не закрывается и не сворачивается, состояние сохраняется | v1 |
| F6 | Любое количество мониторов и произвольная их геометрия; монитор задаётся настройкой, по умолчанию — тот, где курсор | v1 |
| F7 | Явный выход, возвращающий окна на исходные места | v1 |
| F8 | Спрятанное окно не попадает в Alt+Tab и на панель задач | потом |
| F9 | Окно уезжает само, когда фокус ушёл в другое окно — настройкой `hideOnBlur` | v1 |
| F10 | Динамический слот: `Ctrl+Alt+Shift+N` запоминает активное окно, дальше `Ctrl+Alt+N` управляет им | v1 |
| F11 | Автозапуск вместе с системой | потом |
| F12 | Выбор конкретного окна постоянного слота, когда у приложения их несколько | потом |
| F16 | Постоянный слот нельзя перезаписать динамически | v1 |
| F13 | Освобождение отдельного слота хоткеем (сейчас — только очистка всех сразу) | потом |
| F14 | Хоткей возврата фокуса: выдвинуть при необходимости и активировать | v1 |
| F15 | Щелчок по значку приложения на панели задач возвращает припаркованное окно | потом |

## Нефункциональные

| № | Требование |
|---|---|
| N1 | Запуск второго экземпляра не блокирует работу: новый вытесняет старый |
| N2 | Некорректное окно не приводит к падению — программа продолжает работать |
| N3 | Настройки хранятся в исходном файле и не переписываются программой |
| N4 | Любое состояние окна обратимо штатными средствами Windows |
| N5 | Нет фоновых служб, сетевых портов и внешних процессов |
| N6 | Изменение поведения — правка одной строки без пересборки |

## Ограничения

- Windows 11, требуется установленный AutoHotkey v2
- Целевые приложения: VS Code (`Code.exe`), PhpStorm (`phpstorm64.exe`)

## Технические ограничения

- **Анимации нет, если к выбранному краю примыкает другой монитор.**
  Анимация уводит окно за край монитора; будь там соседний экран, окно
  проехало бы по нему на виду. В этом случае окно паркуется сразу, без
  движения. Край при этом не меняется — см. Р3.
- Прятать окно за любой край можно всегда: точка парковки берётся за
  границей всего виртуального рабочего стола, а не за краем монитора.
- Хоткеи ставятся через клавиатурный хук, а не `RegisterHotkey` — см. Р11.
- Динамические слоты живут только пока работает программа: после
  перезапуска окна нужно назначить заново. Хоткея «забыть один слот»
  нет — есть очистка всех сразу; привязка сбрасывается сама, когда
  окно закрывают.
- Клавиши слотов заданы номером и не настраиваются. Настройкой
  выбирается номер слота приложения, а не сочетание.
- Мониторы с разным масштабом (DPI) не проверялись.
- `hideOnBlur` работает только вместе с `activateOnShow`: окно, которое
  не получало фокуса, не может его потерять.
- Пока выдвинуто окно с `hideOnBlur`, работает таймер на 250 мс. Когда
  выдвинутых окон нет, таймер выключен и программа не делает ничего.
- После того как окно убрано хоткеем, фокус остаётся на нём же —
  припаркованном и невидимом. См. Р15.
- Края `top` и `bottom` реализованы, но вживую не проверялись.
